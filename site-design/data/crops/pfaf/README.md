# PFAF offline database

Place `data.sqlite` here via:

```bash
npm run pfaf:download
```

**Source:** [saulshanabrook/pfaf-data](https://github.com/saulshanabrook/pfaf-data) — community scrape of [pfaf.org](https://pfaf.org) (~8,500 plants).

**License / use:** Plant content is © Plants For A Future. Use for personal research and site design. Attribute **pfaf.org**. Do not redistribute this SQLite commercially without an official PFAF database license (sold on pfaf.org). The file is gitignored.

**Why not live scrape?** Fragile and TOS-sensitive. Offline mirror + official paid DB are the supported paths.
