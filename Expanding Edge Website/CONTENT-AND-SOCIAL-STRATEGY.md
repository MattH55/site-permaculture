# Expanding Edge — Keyword, Social & Resource Architecture Strategy

**Goal:** Become the dominant *implementation-grade* permaculture brand in Alberta and Western Canada by owning **useful tools and evergreen systems**, then using social to *route attention into those resources* (not to manufacture endless posts).

**Positioning line (content & social):**  
*Design-build permaculture for Alberta & Western Canada — tools that plan, systems that get built.*

## 2. Social media strategy (resource-first, not post-first)

### Principle

Social is a **distribution system for durable assets**. Every post should point to one of:

- Interactive tool / dashboard  
- Course module or exercise  
- Guide (structured, evergreen)  
- Case study with implementation proof  
- Contact / design consult  

Avoid building a content calendar that only produces “tips.” Tips expire; **tools compound**.

### Channel roles

| Channel | Role | Primary content form | Cadence (start) |
|---------|------|----------------------|-----------------|
| **YouTube** | SEO + trust + demos | Tool walkthroughs, earthworks process, dashboard tours, course lessons | 2 long / month + Shorts from same shoots |
| **Instagram** | Visual proof + local lifestyle | Reels of installs, carousels that *teach one calculator input*, Stories → link tool | 3–5 Reels / week |
| **Facebook** | Alberta acreage groups + 35–55 owners | Group-native value: “use this frost tool”, event posts, case study albums | 3 / week + group participation |
| **LinkedIn** | Farms, land stewards, munis, investors | Dashboards, implementation capacity, Western Canada market narrative | 2 / week |
| **TikTok / Shorts** | Discovery under cold-climate & homestead | 20–45s “watch us stake a contour”, plant hardiness clip → link in bio | 4–7 / week (repurpose) |
| **Email / SMS later** | High-intent nurture | New tool launches, course open, seasonal dashboard alerts | Monthly + product launches |
| **X / Twitter** | Optional secondary | Policy, ag climate, tool releases | As needed |

### Funnel (simple)

```
Awareness (Shorts/Reels: problem + climate)
    → Resource (tool / dashboard / exercise)   ← own this layer
        → Learn deeper (course module / guide)
            → Design tool / contact
                → Implementation quote
```

### Content pillars for social (still not “blog posts”)

1. **Field proof** — earthworks, plantings, before/after (case studies)  
2. **Tool moments** — “we just shipped X calculator; here’s one input”  
3. **Climate reality** — frost, chinook, clay, snowmelt (Alberta-specific)  
4. **Implementation craft** — staking, sequencing, phasing budgets  
5. **Mission scale** — building Canada’s implementation capacity (sparingly)

### 90-day social operating rhythm

| Week type | Focus |
|-----------|--------|
| Week A | Ship or upgrade **1 resource** → 1 YT demo + 5 short clips + email |
| Week B | **Case study / field** content → feed proof into same tools |
| Week C | **Course module** clip series → enroll or free module |
| Week D | **Local geo** (Edmonton / Calgary / county) → city page + tool |

### Metrics that matter

- Resource sessions (tool starts, calculator completions)  
- Design-tool starts from social UTM  
- Contact form with location + interest = implementation  
- Not vanity: likes without clicks  

UTM pattern: `?utm_source=instagram&utm_medium=reel&utm_campaign=swale-calculator`

## 3. Site architecture for continuous production

### Design goals

1. **Evergreen cores** deepen over years (dashboards, plant DB, design tool).  
2. **Modular resources** can ship weekly without redesigning the site.  
3. Every resource has: **problem → tool → related course → CTA**.  
4. Geo pages and case studies **plug into** resources, not the reverse.

### Recommended information architecture

```
/                           Marketing home (services, geo, proof)
/service-areas/             Geo hub
/edmonton/  /calgary/       City landings → tools + case studies
/case-studies/              Proof library
/design/                    Flagship interactive site design tool

/resources/                 ★ NEW hub — all “true resources”
  /resources/tools/         Calculators, generators, checklists-as-apps
  /resources/dashboards/    Live or data-heavy maps & climate panels
  /resources/datasets/      Downloadable / filterable data products
  /resources/templates/     Printable + fillable field sheets (PDF + web)
  /courses/                 ★ Structured learning paths (not blog)
    /courses/cold-climate-fundamentals/
    /courses/water-on-contour/
    /courses/food-forest-establishment/
  /learn/                   Existing Design Toolbox (ethics, principles, drivers)
    … keep and expand …
  /labs/                    Interactive exercises & simulators
    /labs/contour-analysis/ (exists under learn/exercises — promote)

/about/  /contact/
```

### How new content is produced without chaos

| Content type | Lives under | Update model | Social hook |
|--------------|-------------|--------------|-------------|
| Calculator / small tool | `/resources/tools/{slug}/` | Version notes in footer | “New tool: …” |
| Dashboard | `/resources/dashboards/{slug}/` | Seasonal data refresh | Screenshot + link |
| Course | `/courses/{slug}/` modules | Module-by-module ship | Lesson Shorts |
| Lab / exercise | `/labs/{slug}/` | Add scenarios | “Do this on your land” |
| Guide (structured) | `/resources/guides/{slug}/` only if multi-step SOP | Annual review | Carousel of steps → tool |
| Case study | `/case-studies/{slug}/` | When client OK | Proof reel → case study |
| City page | `/{city}/` | Link new tools as they ship | Local hashtags |

### Production system (editorial, not blog)

Treat resources like a **product backlog**:

```
Backlog → Spec (inputs/outputs) → Build → QA on AB test sites
→ Ship under /resources/ → Demo video → 7 social assets → GSC index
```

**Definition of done for a resource**

- [ ] Solves one Tier A/B/C query  
- [ ] Works on mobile  
- [ ] Internal links to design tool + contact  
- [ ] Alberta / Western Canada defaults where data allows  
- [ ] Schema (`SoftwareApplication` / `Course` / `Dataset` as fits)  
- [ ] 1 demo video + UTM landing

## 5. Twenty true resources (not posts, not articles)

Each item is a **product-like asset**: interactive tool, dashboard, dataset, course, lab, generator, or operational system. Social *announces* these; it does not replace them.

### A. Interactive tools & calculators (ship early)

1. **Alberta Frost & Season Dashboard**  
   Inputs: nearest station / lat-long. Outputs: avg last/first frost, frost-free days, GDD bands, chinook note for south AB. Export PDF one-pager for the fridge.

2. **Cold-Climate Plant Finder**  
   Filter by hardiness, height, function (nitrogen fixer, windbreak, edible), moisture, Alberta ecoregion (parkland / prairie / foothills / Peace). Output: shortlist + guild suggestions. (Evergreen DB — grows forever.)

3. **Swale & Contour Spacing Calculator**  
   Inputs: slope %, soil type, rainfall event, run length. Outputs: suggested spacing, estimated storage volume class, overflow warnings. Links to water-management learn pages + earthworks CTA.

4. **Roof & Yard Rainwater Catchment Calculator**  
   Roof area, eavestrough efficiency, monthly precip normals (AB stations). Outputs: cistern size ranges, months of supply for garden irrigation.

5. **Food Forest Density & Starter Guild Builder**  
   Acreage or m², target canopy %, species from Plant Finder. Outputs: plant counts, staggered years 1–5, rough nursery order list.

6. **Shelterbelt / Windbreak Designer**  
   Prevailing wind, field width, goal (snow trap vs full stop vs living fence). Outputs: row count, species roles, setback from buildings/roads (guidance, not legal survey).

7. **Homestead Zone Planner (Lite)**  
   Drag home, barn, garden, septic, driveway on a simple canvas *or* simplified steps that feed the full `/design/` tool. Output: zone 0–5 checklist + “open full site design.”

8. **Earthworks Phase & Rough Budget Builder**  
   Acres, goals (pond / swales / access / planting), soil difficulty. Outputs: phase order (water → access → trees → annuals) + cost bands (low/med/high) + “request quote.”

9. **Pond / Dugout Volume Estimator**  
   Length × width × depth profiles, freeboard, clay vs liner flag. Outputs: volume (m³ / gal), livestock-day estimates, evaporation caution for southern AB.

10. **Grazing & Small-Stock Rotation Sketch Tool**  
    Paddock count, rest days, animal units. Outputs: rough rotation calendar + water/access reminders for integration with permaculture zones.

### B. Dashboards & data products (evergreen, refreshable)

11. **Western Canada Regenerative Site Dashboard (Property Report Lite)**  
    After user draws parcel (hook design tool): auto panel of elevation range, aspect summary, climate summary, soils note, “top 5 design moves.” This is the *shareable* report layer of your design stack.

12. **Alberta Ecoregion Design Packs Dashboard**  
    Toggle Parkland / Dry Mixedgrass / Foothills / Peace / Boreal transition. Each pack: typical constraints, plant lists, water strategies, case-study links. Not an article — a **switchable system panel**.

13. **Seasonal Field Operations Calendar (Interactive)**  
    Month × tasks for AB: prune, plant bare-root, earthworks freeze/thaw windows, mulch, monitor. User checks off tasks; state saved locally. Printable year wall chart.

14. **Watershed & Wet-Area Awareness Map Layer Pack**  
    Guided viewer: how to read wet areas, drainage, and “don’t dig here” risk zones for AB parcels (educational; not replacing surveyors). Pairs with earthworks sales ethically.

15. **Implementation Metrics Dashboard (Public + Client)**  
    Public: anonymized “hectares under regenerative design,” swale-metres, trees planted (brand leadership). Client login later: project milestones. Social gold for LinkedIn.

### C. Courses, labs & certification-style paths (structured learning)

16. **Course: Cold-Climate Permaculture Foundations (Alberta Edition)**  
    6–8 modules: ethics, observation, water, soil, plants, zones, phasing, implementation. Each module ends in a **tool** or **lab**, not a quiz-only dead end. Certificate of completion (branded) optional.

17. **Course: Water on Contour — From Map to Machine**  
    Contours → stakeout → swale/pond sequencing → overflow → planting the water system. Includes your contour lab + swale calculator. Upsell: earthworks crew.

18. **Lab Series: Read Your Land (Interactive Exercises)**  
    Expand contour analysis; add sector mapping lab, microclimate walk simulator (photo + prompts), photo-monitoring station setup. Score or completion badges to encourage finishing.

19. **Field Templates Kit (Fillable System)**  
    Web + PDF: site observation log, client intake, staking checklist, planting day run-of-show, 12-month establishment checklist. “Templates” are resources operators reuse — not blog posts.

20. **Guild & Enterprise Recipe Library (Configurator)**  
    Not essays: selectable “recipes” (e.g. *egg-layer + willows + swale edge*, *market berry alley crop*, *shelterbelt + pasture*). Each recipe = inputs, spacing, labour class, yield window, risks for AB. Generates a one-page plan PDF.

## 8. Guardrails

- **Accuracy:** Climate/plant data labeled with sources and “guidance not engineering stamp.”  
- **Privacy:** Case studies and dashboards anonymize clients unless approved.  
- **Thin content:** No city pages or “tools” that are only 200 words of SEO fluff.  
- **Superlatives:** Keep “building Canada’s largest implementation company” as mission, not fake rank claims.  
- **Comments:** Answer with *links to resources*, not essay threads that never become site assets.
