# SEO Checklist — Expanding Edge Marketing Site

Optimized for **Alberta + Western Canada** market leadership: design-build permaculture, with positioning as Canada’s scale-up implementation company.

## Positioning (do not dilute)

- **Primary geo:** Alberta (Edmonton Capital Region, Calgary/foothills, Central, South, Peace Country)
- **Secondary geo:** Western Canada — BC, Saskatchewan, Manitoba
- **Offer:** Full design-build (site design + earthworks + planting), not consulting-only
- **Aspiration line (compliant):** “Building Canada’s largest permaculture implementation company” — use *building* / *mission* language, not unverifiable “we are currently the largest” claims

## ✓ On-Page SEO

- [x] Unique titles with Alberta / Western Canada / Canada intent
- [x] Meta descriptions ~150–160 chars with CTAs and geo
- [x] H1s match commercial intent (implementation + geo)
- [x] Service Areas page for city/region long-tail
- [x] FAQ + FAQPage schema on homepage
- [x] LocalBusiness + OfferCatalog + WebApplication schema
- [x] Internal links: Services ↔ Design ↔ Service Areas ↔ Contact
- [x] Footer geo + service regions on main pages
- [x] Mobile-responsive; sticky nav; clean URLs

## ✓ Technical SEO

- [x] `robots.txt` (sitemap points to live host)
- [x] `sitemap.xml` includes `/service-areas/`
- [x] Canonicals + Open Graph + Twitter cards
- [x] `lang="en-CA"` on marketing pages
- [x] geo.region / geo.placename on homepage
- [x] Structured data: LocalBusiness, FAQPage, Service, WebApplication
